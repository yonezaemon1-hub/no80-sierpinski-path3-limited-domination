# Research No.80 — Exact 1- and 2-Limited Domination Numbers of Generalized Sierpiński Graphs over the Three-Vertex Path

**Ryutaro Yonezu — Independent Researcher**  
Preprint prepared: 2026-11-22. AI-assisted; **not human peer reviewed**.  
**NOVELTY INCONCLUSIVE · REFERENCES PARTIAL · All rights reserved.**

For generalized Sierpiński graphs over the 3-vertex path $P_3$, the manuscript establishes:

- $\gamma_1^L(S(P_3,n))=2\cdot3^{n-1}$ for $n\geq1$;
- $\gamma_2^L(S(P_3,n))=4\cdot3^{n-2}$ for $n\geq2$, with value 1 for $n=1$.

The notion is a dominating set in which each selected vertex has at most $k$ neighbors outside the set (not k-tuple domination).
